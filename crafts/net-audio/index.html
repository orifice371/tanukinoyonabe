ネットワークオーディオ

Raspberry Piを使って、音楽をネットワーク経由で再生する装置を作る。
音を出すところから始まり、音量調整や表示装置まで、少しずつ手を加えていった。

完成したもの

Raspberry Piを中心に、DAC、アンプ、スピーカーを組み合わせた 自作ネットワークオーディオ。

構成

  • Raspberry Pi 3B
  • Volumio 4.119
  • DAC：PCM5102A
  • メインアンプ：YDA138-E
  • OLED：1.3インチ 128×64

Raspberry Piで音楽を再生し、DACでアナログ音声に変換。 アンプで増幅してスピーカーを鳴らす構成。

製作過程

1. Raspberry Piで音を出す

Raspberry Pi 3BにVolumioを導入。 PCM5102AのDAC基板を接続して、まずは音が出るところまで進めた。

2. アンプとスピーカー

YDA138-Eのアンプ基板を接続。 手元にあったスピーカーを組み合わせて、音を鳴らしてみる。

3. 音量調整とミュート回路

Volumioのソフトウェア音量だけでは調整が難しかったため、 LM1972Mを使ったハードウェア音量調整を検討。 電源投入時や切断時のポップノイズ対策として、リレーによる スピーカーのミュート回路も製作した。

4. OLED表示

1.3インチの小さなOLEDを追加。 曲名などは操作端末で確認できるので、こちらには遊び心のある表示を。 眠る猫のアニメーションを表示することにした。

使用した部品

  • Raspberry Pi 3B
  • PCM5102A DAC基板
  • YDA138-E アンプ基板
  • LM1972M 音量調整IC
  • リレー：942H-2C-5DS、TQ2-5V（使用状況は要確認）
  • 1.3インチ OLEDディスプレイ

完成・これから

音楽を再生する装置としてだけでなく、 小さな表示装置や回路も組み込んだ工作になった。
